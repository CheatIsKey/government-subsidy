**먼저 정해야 할 큰 항목 (설계 전체에 영향을 줌)**

| 번호 | 내용 |
|---|---|
| Q-06 | 조사 문서에는 **지역 코드가 없습니다.** 그래서 "서울 사는"이라는 조건을 어떻게 처리할지 정해지지 않았습니다. |
| Q-07 | 자격 조건(supportConditions) 값의 형식과 뜻이 미확인입니다. 이게 정해지기 전에는 조건으로 결과를 **잘라내지 말고 순위 가산점으로만** 쓰자고 추천합니다. |
| Q-02, Q-04 | Elasticsearch와 bge-m3를 데모에서 어디서 돌릴지 정해야 합니다. 비용이 가장 많이 드는 부분입니다. |
| Q-03 | Elasticsearch 무료 라이선스에서 RRF 기능을 쓸 수 있는지 미확인입니다. 그래서 앱 안에서 직접 RRF를 계산하자고 추천합니다. |
| Q-21 | SSE 스트리밍과 "인용 사후 검증"은 서로 부딪힙니다. 글자를 먼저 보내고 나서 검증하게 되기 때문입니다. |
| Q-17 | 로그인이 없으므로 운영 기능(동기화 수동 실행 등)을 보호할 방법을 정해야 합니다. |


| 구분 | 내용 |
|---|---|
| 인터페이스 | 공개 API는 `POST /api/v1/chat`, `POST /api/v1/chat/stream`(SSE, Q-18), `GET /api/v1/benefits/{id}`, `GET /api/v1/search`(Q-26)입니다. 에러는 RFC 9457 형식에 `code`와 `traceId`를 더합니다. NO_EVIDENCE와 LLM_FAILED를 **200으로 돌려주는 설계**는 따로 확인해 주세요. |
| 데이터 모델 | RDB가 기준 원본이고, ES는 다시 만들 수 있는 복사본입니다. 자격 조건은 세로형(코드 하나당 한 행)으로 저장합니다. 목록과 상세에서 이름이 다른 3쌍은 따로 저장합니다. 임베딩 벡터는 RDB에 저장하지 않자고 제안합니다. 그 대신 모델을 바꾸지 않고 재구축할 때도 다시 임베딩해야 해서, CPU 비용이 듭니다(전체 건수 [미확인]). 이 비용이 크면 RDB나 파일에 저장하는 방안도 있습니다. |
| 권한 | 공개 경로는 모두 익명입니다. 운영 경로는 공개 인터넷에 노출하지 않는 방안을 추천합니다(Q-17). IP는 ALB가 붙인 X-Forwarded-For만 믿습니다. |
| 보안 | 개인정보는 가린 뒤 외부 LLM에 보내고, 원문은 저장하지 않습니다. 공공 API 키가 URL 쿼리에 들어갈 가능성이 있어(파라미터 이름 [미확인]) 로그에서 가립니다. 원문과 LLM 출력은 이스케이프하고, 링크는 http/https만 허용합니다. |
| 외부 연동 | Gov24 API(미확인 항목이 많음, Q-29/Q-30), Gemini(약관·한도·Spring AI 모듈 미확인, Q-05), Ollama, ES(호스팅·라이선스, Q-02/Q-03). 테스트에서는 모두 가짜 서버나 컨테이너를 씁니다. |
| 마이그레이션 | DB는 Flyway(Q-42)로 관리합니다. ES는 버전을 붙인 인덱스와 별칭 교체로 바꾸고, 되돌릴 때는 별칭을 다시 바꿉니다. 임베딩 모델을 바꾸면 전체를 다시 임베딩하고, 질문 임베딩 설정도 함께 바꿔야 합니다(`_meta`가 다르면 벡터 검색을 하지 않음). 지문 규칙이 바뀌는 경우는 hash_version으로 관리합니다. |
| 프로세스 구조 | 코드베이스 하나에 실행 진입점이 둘입니다(웹 서버, 동기화 배치). 동기화 Scheduled Task와 API 서버가 같은 DB 락 테이블을 씁니다. |
| 추가 확인 사항 | 상담이 DB 장애 중에도 동작하게 하려면 상담 경로가 ES만 읽어야 합니다. 이 때문에 ES 문서에 답변과 인용에 필요한 필드(서비스명, 기관명, 상세조회URL 등)를 넣었습니다. |

제가 사실로 확인하지 못해서 표시해 둔 내용입니다. 실제 공식 문서로 확인해야 합니다.
- ES 무료 라이선스에서 RRF retriever를 쓸 수 있는지
- Ollama에서 bge-m3를 제공하는지와 차원이 1024인지
- Spring AI의 Gemini(API 키 방식) 지원 모듈
- ALB 유휴 시간 초과 기본값
- Fargate에서 ES 디스크를 쓰기에 적합한지
- Gemini 무료 등급 약관과 한도
- 공공데이터 이용허락 조건
