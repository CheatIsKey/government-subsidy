# 요구사항 목록

> 상태: **1단계 승인 (2026-11-14).** [미확인] 항목은 실제 API 확인 후 바뀔 수 있고, 바꿀 때는 다시 승인받는다.
> 표기: **[미확인]** = `docs/research/gov24-api.md`의 미확인 항목에 기대는 요구사항. 실제 API 키로 호출해 보기 전에는 확정할 수 없음.
> **(Q-nn)** = `docs/open-questions.md`의 확인 필요 번호.

## 0. 용어 풀이

| 용어 | 쉬운 설명 |
|---|---|
| 공공 API | 행정안전부가 공개한 "공공서비스(혜택) 정보" 데이터를 프로그램으로 받아 오는 창구 |
| 동기화(sync) | 공공 API 데이터를 받아 와서 우리 DB에 똑같이 맞춰 두는 작업 |
| 증분 동기화 | 전부 다시 받지 않고 **바뀐 것만** 반영하는 동기화 |
| RDB | 표(테이블) 형태로 데이터를 저장하는 일반 데이터베이스 (MySQL, PostgreSQL 등) |
| ES (Elasticsearch) | 검색 전용 엔진. 글 검색과 "의미가 비슷한 글" 검색을 빠르게 해 준다 |
| 인덱스 / 색인 | ES에 검색용으로 넣어 둔 데이터 묶음 / 그 데이터를 넣는 작업 |
| nori | ES의 한국어 형태소 분석기. "월세를"을 "월세"+"를"처럼 나눠 준다 |
| BM25 | 단어가 얼마나 겹치는지로 점수를 매기는 전통적인 키워드 검색 방식 |
| 임베딩(embedding) | 글의 의미를 숫자 1024개짜리 목록(벡터)으로 바꾼 것. bge-m3 모델이 만든다 |
| kNN 벡터 검색 | 질문 벡터와 가장 가까운(의미가 비슷한) 문서 k개를 찾는 검색 |
| 하이브리드 검색 / RRF | BM25 결과와 벡터 결과를 합치는 방식. RRF(Reciprocal Rank Fusion)는 점수 대신 "몇 등이었는지"로 합친다 |
| LLM | 대규모 언어 모델. 답변 문장을 만든다 (로컬은 EXAONE, 데모는 Gemini) |
| RAG | 검색해 온 문서를 LLM에 같이 주고, 그 문서를 근거로 답하게 하는 방식 |
| 가드레일 | AI가 근거 없는 말을 하지 않도록 막는 안전장치 |
| 환각(hallucination) | AI가 사실이 아닌 내용을 그럴듯하게 지어내는 것 |
| 프롬프트 주입 | 사용자가 "이전 지시를 무시해" 같은 문장을 넣어 AI를 조종하려는 공격 |
| SSE | 서버가 답변을 한 번에 보내지 않고 글자 단위로 조금씩 흘려보내는 방식 |
| Fargate | AWS가 서버 관리를 대신해 주는 컨테이너 실행 환경. Scheduled Task는 정해진 시각에 한 번 실행되는 작업 |
| nDCG@k / Recall@k | 검색 품질 점수. 상위 k개 안에 정답이 얼마나, 얼마나 위쪽에 있는지를 본다 |
| p50 / p95 | 응답 시간을 줄 세웠을 때 50% / 95% 지점의 값. p95는 "느린 편일 때"를 보여 준다 |
