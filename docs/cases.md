# 케이스 목록

> 상태: **1단계 승인 (2026-11-14).** [미확인] 항목은 실제 API 확인 후 바뀔 수 있고, 바꿀 때는 다시 승인받는다. 사람이 빼거나 고친 케이스는 맨 아래 "변경 기록"에 이유와 함께 적는다.
> 케이스 ID: `<요구사항ID>-<관점 글자><번호>`. 관점 글자: **N** 정상, **E** 예외, **B** 경계값, **A** 권한, **F** 실패(타임아웃·부분 실패·중복 요청), **C** 동시성, **M** 데이터 마이그레이션.
> 테스트 종류: **단위** (클래스 하나, 외부 없음), **통합** (WireMock(가짜 외부 서버), Testcontainers(ES+nori, DB)), **회귀** (전에 고친 문제가 다시 생기지 않는지 계속 확인), **평가** (실제 모델로 따로 실행. CI(자동 테스트)에는 넣지 않음), **수동** (배포 환경 점검).
> **[미확인]** = gov24-api.md 미확인 항목에 기대는 케이스. 실제 키로 확인한 뒤 기대 결과를 확정한다.

## SYNC-1 목록 전체 수집

| ID | 관점 | 상황 | 기대 결과 | 테스트 |
|---|---|---|---|---|
| SYNC-1-N1 | 정상 | DB가 비어 있고 totalCount=250, perPage=100 | 3페이지를 호출해 250건을 생성. run=SUCCEEDED, created=250 | 통합 |

| SYNC-1-B1 | 경계값 | totalCount가 perPage의 배수 (예: 2000, perPage 1000) | totalCount로 필요한 페이지 수를 계산해 정확히 그만큼만 호출 (2000건 → 2번). 에러 없음 (실측: 마지막 다음 페이지는 data=[]) | 단위 |
| SYNC-1-B2 | 경계값 | 마지막 페이지가 perPage보다 적음 | 그 페이지에서 멈춤 | 단위 |
| SYNC-1-B3 | 경계값 | totalCount=0, data=[] | 기존 데이터는 그대로. run=FAILED `SOURCE_EMPTY`. 삭제 판정 안 함 | 통합 |
| SYNC-1-B4 | 경계값 | perPage 설정값 | 기본 1000. 설정값이 2000을 넘으면 기동 때 설정 오류 (실측: 3000 이상은 data 없이 "정상" 응답) | 단위 |
| SYNC-1-E1 | 예외 | 같은 서비스ID가 한 실행 안에서 두 번 나옴 | **처음 나온 1건**만 저장. 나머지는 중복 건수로 기록 | 단위 |
| SYNC-1-E2 | 예외 | 페이지를 넘기는 사이 원본이 바뀌어 모은 건수 ≠ totalCount | run=PARTIAL, 삭제 판정 안 함, 차이를 기록 | 통합 |
| SYNC-1-E3 | 예외 | totalCount>0인데 어떤 페이지의 data가 비었음 | 그 페이지는 실패로 기록(SYNC-6 재시도 대상)하고, totalCount로 계산한 마지막 페이지까지 **계속 호출** | 단위 |
| SYNC-1-E4 | 예외 | HTTP 200인데 응답에 `data` 칸 자체가 없음 (예: `{"code":0,"msg":"정상"}`) | 0건으로 보지 않고 그 페이지를 실패로 기록 (SYNC-6 재시도 대상). 중간 페이지면 다음 페이지를 계속 호출. **1페이지가 실패해 totalCount를 알 수 없으면 그 자리에서 멈춤.** run은 SUCCEEDED가 될 수 없고(PARTIAL 또는 FAILED), 삭제 판정 안 함 | 단위·통합 |
| SYNC-1-M1 | 마이그레이션 | 첫 배포. 스키마도 데이터도 없음 | 스키마 마이그레이션(Q-42)이 테이블과 코드 사전 초기값을 만들고, 첫 FULL 실행이 전부 채움 | 통합 |

해당 없음: 권한(사용자 입력 없이 외부만 호출. 키 처리는 OPS-5), 동시성(SYNC-7에서 다룸).

## SYNC-7 중복 실행 방지

| ID | 관점 | 상황 | 기대 결과 | 테스트 |

> "키 없음" = 원래 값(예: `ab+c/d==`), 대문자 인코딩(`ab%2Bc%2Fd%3D%3D`), 소문자 인코딩(`ab%2bc%2fd%3d%3d`), 부분 인코딩(`ab%2Bc/d==`) 네 형태가 하나도 나오지 않음.
