# 공공서비스(혜택) 정보 API 조사 (Gov24)

- 출처: https://www.data.go.kr/data/15113968/openapi.do (행정안전부, 2026-11-14 확인. 페이지 수정일 2025-12-29)
- 형식: REST, JSON/XML, 무료. 업데이트 주기: 페이지 표기 "실시간"
- 인증: 서비스 키 필요 (키 없이 호출 시 HTTP 401 확인). 파라미터 이름은 미확인
- Swagger 문서: `infuser.odcloud.kr/oas/docs?namespace=15113968/v1` 은 404 — 미확인

> **표시 규칙:** "미확인"이라고 적힌 것은 실제 키로 호출해서 확인해야 한다.

## 엔드포인트

| 경로 | 용도 | 요청 파라미터 |
|---|---|---|
| `GET /api/gov24/v3/serviceList` | 서비스 목록 | page, perPage, returnType, `cond[소관기관유형::LIKE]`, `cond[사용자구분::LIKE]`, `cond[등록일시::GT/GTE/LT/LTE]`, `cond[수정일시::GT/GTE/LT/LTE]` |
| `GET /api/gov24/v3/serviceDetail` | 서비스 상세 | page, perPage, returnType (단건 조회 필터는 페이지에 없음 — 미확인) |
| `GET /api/gov24/v3/supportConditions` | 지원 조건(자격 코드) | `cond[서비스ID::EQ]`, page, perPage, returnType |

응답 공통: `page`, `perPage`, `currentCount`, `totalCount`, `data[]` (`matchCount`는 페이지에 없음 — 미확인)

## serviceList 필드
서비스ID, 서비스명, 서비스목적요약, 지원대상, 선정기준, 지원내용, 신청방법, 신청기한, 지원유형, 서비스분야, 사용자구분, 소관기관유형, 소관기관명, 소관기관코드, 부서명, 접수기관, 전화문의, 상세조회URL, 조회수, 등록일시, 수정일시

## serviceDetail 필드
서비스ID, 서비스명, 서비스목적, 지원대상, 선정기준, 지원내용, 신청방법, 신청기한, 지원유형, 구비서류, 본인확인필요구비서류, 공무원확인구비서류, 법령, 자치법규, 행정규칙, 접수기관명, 소관기관명, 문의처, 온라인신청사이트URL, 수정일시

목록과 이름이 다른 필드: 서비스목적요약↔서비스목적, 접수기관↔접수기관명, 전화문의↔문의처

## supportConditions 코드 (서비스ID당 한 줄로 추정 — 미확인, 값 형식 미확인)

| 묶음 | 코드 |
|---|---|
| 성별 | JA0101 남성, JA0102 여성 |
| 나이 | JA0110 대상연령 시작, JA0111 대상연령 끝 (값 필드로 보임) |
| 중위소득 | JA0201 0~50%, JA0202 51~75%, JA0203 76~100%, JA0204 101~200%, JA0205 200% 초과 |
| 생애·대상 | JA0301 예비부모/난임, JA0302 임산부, JA0303 출산/입양, JA0313 농업인, JA0314 어업인, JA0315 축산업인, JA0316 임업인, JA0317 초등학생, JA0318 중학생, JA0319 고등학생, JA0320 대학(원)생, JA0322 해당없음, JA0326 근로자, JA0327 구직자/실업자, JA0328 장애인, JA0329 국가보훈대상자, JA0330 질병/질환자 |
| 가구 | JA0401 다문화가족, JA0402 북한이탈주민, JA0403 한부모/조손, JA0404 1인가구, JA0410 해당없음, JA0411 다자녀, JA0412 무주택세대, JA0413 신규전입, JA0414 확대가족 |
| 창업 단계 | JA1101 예비창업자, JA1102 영업중, JA1103 생계곤란/폐업예정 |
| 소상공인 업종 | JA1201 음식점업, JA1202 제조업, JA1299 기타 |
| 기업 유형 | JA2101 중소기업, JA2102 사회복지시설, JA2103 기관/단체 |
| 산업 | JA2201 제조업, JA2202 농림어업, JA2203 정보통신업, JA2299 기타 |

같은 이름(제조업, 기타)이 다른 코드로 두 번 나온다 → 이름이 아니라 **코드로** 다룬다.

## 미확인 목록 (실제 키 발급 후 확인)
- 전체 건수, 하루 호출 한도, perPage 최대값
- 날짜 형식(등록일시·수정일시), 빈 값이 `""`인지 `null`인지
- serviceDetail 단건 조회 방법
- 서비스 키 파라미터 이름
- `수정일시` 필터로 증분 동기화(바뀐 것만 받아오기)가 실제로 되는지
